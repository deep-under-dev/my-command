# Codebase Onboarding

Generate a comprehensive onboarding guide for new contributors to this codebase.

## Tasks

1. **Project Overview**
   - Analyze project structure and architecture
   - Identify main technologies and frameworks
   - Document entry points and core modules

2. **Setup Guide**
   - Prerequisites and dependencies
   - Installation steps
   - Environment configuration
   - Common setup issues and solutions

3. **Development Workflow**
   - Branch naming conventions
   - Commit message format
   - PR process and review guidelines
   - Testing requirements

4. **Key Concepts**
   - Domain-specific terminology
   - Important design patterns used
   - Critical business logic areas

5. **Quick Start Tasks**
   - Suggest 3-5 good first issues for newcomers
   - Identify low-risk areas for initial contributions

## Output

Create `ONBOARDING.md` in the project root with all the above information, formatted for easy reading and navigation.
