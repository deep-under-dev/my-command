# /prd - Product Requirements Document 생성

## Usage
```
/prd "기능 또는 프로젝트 설명"
```

## Purpose
상세한 PRD(제품 요구사항 문서)를 생성한다. 개발 전 기획 단계에서 사용.

## Output Format

```markdown

## 1. 개요 (Overview)
### 1.1 목적
[이 기능이 해결하는 문제]

### 1.2 배경
[왜 이 기능이 필요한지, 비즈니스 컨텍스트]

### 1.3 목표

- 주요 목표 2
- 성공 지표 (KPI)

---

## 2. 사용자 스토리 (User Stories)

[페르소나 정의]

### 2.2 사용자 시나리오
| ID | As a... | I want to... | So that... |
|----|---------|--------------|------------|
| US-01 | [역할] | [행동] | [가치] |
| US-02 | [역할] | [행동] | [가치] |

### 2.3 사용자 플로우
```
[시작] → [단계1] → [단계2] → [완료]
```

---
```

## Rules
- 사용자 관점에서 작성
- 구체적인 수치와 기준 제시
- 모호한 표현 지양 (예: "빠르게" → "3초 이내")
- 우선순위 명확히 구분 (P0/P1/P2)
- 검증 가능한 요구사항으로 작성
