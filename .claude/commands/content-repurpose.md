# Content Repurposing

Transform content for platform-native distribution across X, LinkedIn, TikTok, YouTube, and newsletters.

## Usage

```
/content-repurpose "source content or URL" [platforms: x|linkedin|tiktok|youtube|newsletter|all]
```

## Platform Guidelines

### X (Twitter)
- **Length**: < 280 chars (thread if needed)
- **Style**: Punchy, opinionated, conversational
- **Format**: Hook → Insight → CTA
- **Tips**: Use line breaks, avoid links in first tweet

```
Hook tweet (standalone value)
↓
Thread (if expanding)
↓
CTA tweet (follow/subscribe/link)
```

### LinkedIn
- **Length**: 1,300 chars optimal
- **Style**: Professional but human, storytelling
- **Format**: Hook line → Story → Lesson → Question
- **Tips**: First line is everything, use emojis sparingly

```
Attention-grabbing first line.

Story or context (2-3 paragraphs)

Key insight or lesson

Question to drive engagement?
```

### TikTok/Reels Script
- **Length**: 30-60 seconds
- **Style**: Fast-paced, visual, hook in 1-3 sec
- **Format**: Hook → Content → CTA
- **Tips**: Write for spoken word, include visual cues

```
[HOOK - 0:00-0:03]
"Did you know..."

[CONTENT - 0:03-0:45]
Main points with visual transitions

[CTA - 0:45-0:60]
Follow for more / Comment your take
```

### YouTube
- **Title**: Curiosity gap or clear value prop
- **Description**: Hook, timestamps, links, keywords
- **Thumbnail text**: 3-5 words max
- **Script structure**: Hook (30s) → Intro → Sections → CTA

### Newsletter
- **Subject line**: Specific value, curiosity, or urgency
- **Preview text**: Complement (not repeat) subject
- **Format**: Personal note → Main content → Resources → CTA

## Repurposing Matrix

| Source | → X | → LinkedIn | → TikTok | → Newsletter |
|--------|-----|------------|----------|--------------|
| Blog post | Key insight thread | Story angle | Quick tip video | Featured + commentary |
| Podcast | Quote clips | Lesson post | Highlight reel | Episode recap |
| Video | Quote tweets | Behind-scenes | Clips | Transcript excerpt |
| Thread | - | Expand + context | Talking head | Compile + expand |

## Quality Checklist

- [ ] Hook grabs attention in < 3 seconds
- [ ] Platform-native format (not copy-paste)
- [ ] Clear value for the audience
- [ ] Appropriate tone for platform
- [ ] CTA matches platform behavior
- [ ] Hashtags/keywords where relevant
