# Article Writing

Write long-form content: guides, newsletters, blog posts, documentation.

## Usage

```
/article "topic" [format: guide|newsletter|blog|doc]
```

## Workflow

1. **Research** - Gather key points and structure
2. **Outline** - Create logical flow with headers
3. **Draft** - Write with voice consistency
4. **Polish** - Edit for clarity and engagement

## Structure

```markdown
# Title (compelling, specific)

## Introduction
- Hook the reader
- State the value proposition
- Preview what's coming

## Main Sections (3-5)
- One concept per section
- Use subheadings for scannability
- Include examples/evidence

## Conclusion
- Summarize key takeaways
- Call to action if appropriate
```

## Voice Guidelines

- **Conversational** - Write like you're explaining to a smart friend
- **Specific** - Replace vague claims with concrete details
- **Active** - "We built X" not "X was built"
- **Scannable** - Bullets, headers, bold for key points

## Format-Specific Tips

### Guide
- Step-by-step structure
- Code examples where relevant
- Troubleshooting section

### Newsletter
- Personal opening
- 3-5 curated items
- Brief commentary on each

### Blog Post
- Strong opinion or unique angle
- Personal experience/story
- Shareable quotes

### Documentation
- Task-oriented
- Prerequisites upfront
- Copy-paste ready examples

## Quality Checklist

- [ ] Does the title promise value?
- [ ] Is the intro < 3 paragraphs?
- [ ] Can readers skim and get value?
- [ ] Are claims backed by specifics?
- [ ] Clear next step/CTA?
