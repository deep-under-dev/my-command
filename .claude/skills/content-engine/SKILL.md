# Content Engine Skill

Platform-native content repurposing for X, LinkedIn, TikTok, YouTube, newsletters.

## Purpose
Transform source content into platform-optimized versions automatically.

## Platform Specs

### X/Twitter
- Max 280 chars (thread for longer)
- Hook in first line
- 1-2 hashtags max
- Visual-first if possible

### LinkedIn
- Professional tone
- 1300 char sweet spot
- Use line breaks for readability
- End with question/CTA

### TikTok/YouTube Shorts
- Hook in first 3 seconds
- Script format with timestamps
- Trending audio suggestions
- Caption overlay text

### Newsletter
- Personal, conversational
- One main takeaway
- Clear CTA
- 500-800 words ideal

## Workflow

```
1. Analyze source content
2. Extract key messages
3. Adapt to each platform's format
4. Maintain core message across all
5. Output ready-to-post versions
```

## Output Format
```markdown
## Content Package: [Topic]

### X Thread
[Ready to post]

### LinkedIn Post
[Ready to post]

### Short-form Script
[With timestamps]

### Newsletter Draft
[Ready to edit]
```
