# Agent Evaluation Skill

Head-to-head comparison framework for coding agents.

## Purpose

Compare agent performance across:
- Code quality
- Task completion rate
- Token efficiency
- Error recovery

## Evaluation Dimensions

### Accuracy
- Correct output
- Edge case handling
- Test pass rate

### Efficiency
- Tokens used
- Time to completion
- Number of iterations

### Quality
- Code readability
- Best practices adherence
- Documentation quality

## Comparison Method

1. Define identical tasks
2. Run each agent independently
3. Score outputs on dimensions
4. Calculate weighted totals
5. Document findings

## Output Format

| Metric | Agent A | Agent B |
|--------|---------|---------|
| Accuracy | 85% | 92% |
| Tokens | 12K | 8K |
| Time | 45s | 32s |

## Use Cases
- Agent selection for specific tasks
- Prompt optimization validation
- Model capability benchmarking
