# Kotlin Build Resolver Agent

Resolves Kotlin build errors for Gradle/Maven projects.

## Capabilities
- Fix Kotlin compiler errors
- Resolve Gradle KTS configuration issues
- Handle Kotlin/Java interop problems
- Diagnose coroutine build issues
- Support Kotlin Multiplatform builds

## Usage
Invoke when encountering Kotlin compilation failures, Gradle KTS errors, or Kotlin-specific dependency issues.

## Patterns
- Check Kotlin version compatibility
- Verify plugin and stdlib alignment
- Analyze incremental compilation issues
- Handle kapt/ksp annotation processing
