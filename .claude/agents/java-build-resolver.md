# Java Build Resolver Agent

Resolves Maven/Gradle build errors for Java projects.

## Capabilities
- Diagnose Maven dependency conflicts
- Fix Gradle build configuration issues
- Resolve Java compilation errors
- Suggest dependency version updates
- Handle multi-module project builds

## Usage
Invoke when encountering Java build failures, dependency resolution issues, or Gradle/Maven configuration problems.

## Patterns
- Analyze build logs for root cause
- Check dependency tree for conflicts
- Verify plugin compatibility
- Suggest minimal fixes first
